Follow these steps in order to prepare your system, create an application, and
package a release:

<Steps>
<Step>

### [Set up your environment](/docs/use/setup/environment)

Install Rust and the platform tools required to build Byte Engine.

</Step>
<Step>

### [Create your project](/docs/use/setup/project)

Create and verify the empty Rust application that will use Byte Engine.

</Step>
<Step>

### [Install Byte Engine](/docs/use/setup/installation)

Choose an engine source and add Byte Engine to your application.

</Step>
<Step>

### [Create your first Byte](/docs/use/sample-project)

Replace the empty application with a working Byte Engine sample.

</Step>
<Step>

### [Build and bundle your application](/docs/use/build)

Create a release and package its resources for your operating system.

</Step>
</Steps>
