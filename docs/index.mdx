Use Byte Engine to build games and interactive applications in Rust. Its modular
crates cover graphics, audio, input, resources, networking, physics, and retained
UI without hiding the lower-level systems from you.

Each section of this documentation answers one kind of question. Choose yours:

- [Requirements](/docs/requirements) and [Get started](/docs/get-started): what
  do I need, and how do I set up my first application?
- [Use](/docs/use): how do I make my application do this? One task per page,
  from setup to a bundled release.
- [Contribute](/docs/develop): how do I change the engine, and what must my
  change keep true? Workflow pages and a design note for each system.
- [Reference](/docs/reference): what exactly is this language, format, or
  model, and what does it accept? Specifications, with no code.
- [API](/docs/api/latest): what does this Rust item or HTTP endpoint do?
  Generated from the source.
