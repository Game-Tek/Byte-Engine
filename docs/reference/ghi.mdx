The graphics hardware interface (GHI) is the crate through which the renderer
talks to Vulkan on Linux, Metal on macOS, and Direct3D 12 on Windows. This
page specifies its objects, resources, and enumerations, the layout of the
data it shares with shaders, and the state of each backend. How the loader
and renderer share a device is in the
[loading timeline](/docs/develop/rendering/loading) design note.

## Objects

| Object | Role | Rules |
| --- | --- | --- |
| Instance | Enumerates devices and creates one with the queues requested. | Features requested on the instance and the device merge. |
| Device | Owns the GPU and its allocator, and creates contexts. | A context, then the device, then the instance are dropped in that order. |
| Context | Owns the GPU resources created through it. | May move between threads but belongs to one thread at a time. Contexts that submit to the same native queue share one lock. |
| Queue | Submits frames and standalone command buffers. | Selected by workload: raster, ray tracing, compute, transfer, video, or I/O. |
| Frame | A per-frame view of a queue's context. | At most 3 frames in flight. A frame key carries the frame index and the sequence index, the frame index modulo the frames in flight. |
| Command buffer recording | Records passes, copies, clears, blits, and transfers, then executes with a synchronizer. | Counters are started once per frame and measure whole passes. Unordered groups don't nest. |
| Synchronizer | One native primitive per frame sequence. | Waited, polled without blocking, or signaled by an execution. |
| Swapchain | Bound to a window with a presentation mode and an image count. | Acquiring an image may block until the previous submission of that sequence allows reuse, and returns nothing when no image is available. |
| Window and input | A per-process application object creates windows and polls events. | Every window is dropped before the application. |

A pipeline binds descriptor sets by their layout, in any order; a set for a
layout the pipeline doesn't declare is ignored, and a draw or dispatch with a
declared layout unbound fails. Push constants are written at an offset within
the pipeline's declared ranges.

## Resources

| Resource | Rule |
| --- | --- |
| Static buffer | Zero-initialized, not resizable, one copy that every frame in flight reads; write only ranges no submitted frame reads. |
| Dynamic buffer | One copy per frame in flight, each keeping what its last frame wrote; resizable. |
| Image | Starts without valid contents. A dynamic image has one copy per frame; a grouped image may share memory with images whose lifetimes don't overlap. Region uploads cover uncompressed single-layer 2D color images at mip 0. |
| Cube images | Six layers, or a multiple of six for an array. |
| Sampler | Linear filtering, weighted-average reduction, linear mips, clamp addressing, no anisotropy, and a zero LOD range by default. Devices limit sampler counts. |
| Shader | SPIR-V, keyed SPIR-V, DXIL, HLSL, Metal library, or Metal source. GLSL compiles only on Linux. |
| Descriptor set layout | At most 64 resources with distinct slots. Equal layouts have equal identities and are interchangeable. |
| Raster pipeline | Clockwise front faces, back-face culling, solid fill, and depth writes by default. |
| Acceleration structure | Triangle geometry with 16-bit or 32-bit indices. See [Ray tracing](#ray-tracing). |
| Ray tracing pipeline and shader binding table | A ray generation shader and its hit groups, and the records that map hits to them. See [Ray tracing](#ray-tracing). |
| Counter | At most 512 per frame. Its duration is that of the most recently completed frame. |
| Texture readback | The base mip of one layer of a color image with the transfer-source use, in a format other than RGB8, RGB16, or depth. The handle is consumed by the read. |

## Enumerations

| Enumeration | Values |
| --- | --- |
| Layouts | Undefined, render target, transfer, present, read, general, indirect |
| Uses | Vertex, index, uniform, storage, indirect, image, render target, depth stencil, transfer source, transfer destination, acceleration structure build, clear, input attachment |
| Device accesses | CPU read, CPU write, GPU read, GPU write, and the combinations device only, host only, host to device, and device to host |
| Data types | Float through float4, u8, u16, u32, int through int4, uint through uint4 |
| Shader types | Vertex, fragment, compute, task, mesh, ray generation, closest hit |
| Filtering, reduction, addressing | Closest or linear; weighted average, minimum, or maximum; repeat, mirror, clamp, or border |
| Presentation modes | Immediate, FIFO, mailbox |
| Clear values | None, a color, four integers, or a depth |
| Load and store operations | Load, clear, or discard; store or discard |

Formats cover one to four channels at 8, 16, and 32 bits in float, unsigned
normalized, signed normalized, and sRGB encodings, plus the packed
`RGBu11u10`, the swapchain's `BGRAu8` and `BGRAsRGB`, `Depth16`, `Depth32`,
`U32`, and the block-compressed `BC5`, `BC5SNORM`, `BC7`, and `BC7SRGB`.
Metal maps three-channel formats to their four-channel equivalents and some
8-bit and 32-bit formats to the nearest native format. Texture copies align
rows to 256 bytes.

## Plain data

The `pod` module holds the CPU types shaders read and write, each mirroring a
BESL type. A vector is its components packed back to back and aligned to one
component, so a three-float vector is 12 bytes and a four-float vector is 16
without padding. A matrix is its column vectors back to back, so a four-by-four
matrix is 64 bytes and a four-by-three matrix 48. A shader boolean is 32 bits.
Converting the engine's matrix transposes it into columns on Metal, because
Metal reads columns where the other backends read rows.

## Resource I/O

A context can create a resource I/O queue that loads files straight into
buffers and image regions.

| Backend | Sources | Destinations | Compression |
| --- | --- | --- | --- |
| Metal | Files | Buffers, image regions | zlib, LZFSE, LZ4, LZMA, LZ bitmap |
| Direct3D 12 | Files | Buffers, image regions | GDeflate |
| Vulkan | None; creating a queue fails | | |

Both supported backends can cancel a request. A request can be pending,
complete, cancelled, or failed.

## Ray tracing

A context supports ray tracing when its device was created with the ray
tracing feature and the GPU supports it. Only Metal supports it; Vulkan and
Direct3D 12 report no support. Rays find hits in a top-level structure, whose
instances place bottom-level structures in the world. A ray tracing pipeline
launches a ray generation shader over a grid, and that shader runs the hit
group of each hit's record, as a shader binding table maps it.

| Object | Definition | Rules |
| --- | --- | --- |
| Triangle geometry | Indexed triangles: a range of vertex positions, each three 32-bit floats at a fixed stride, and 16-bit or 32-bit indices that start at a buffer offset. | Both buffers have the acceleration structure build use. Positions start at a multiple of 4 bytes, with a stride of at least 12 bytes in steps of 4. Indices start at a multiple of their size, and each names a vertex of the position range. The vertex count is the size of the position range divided by its stride. Every triangle is opaque. |
| Bottom-level structure | One or more triangle geometries, numbered from 0 in the order given at creation. | Built once. Its size is known from creation and shrinks when it compacts. |
| Instance | One placement of a bottom-level structure. | See [Instances](#instances). |
| Top-level structure | The instances rays traverse, up to the count given at creation. | One copy per frame in flight. |
| Ray tracing pipeline | A ray generation shader and one or more hit groups, numbered from 0 in the order given at creation. A hit group is one closest-hit shader. | See [Pipelines](#pipelines). |
| Shader binding table | Records numbered from 0, each naming a hit group of one ray tracing pipeline. | See [Shader binding tables](#shader-binding-tables). |

### Instances

| Field | Definition |
| --- | --- |
| Transform | Three rows of four 32-bit floats that map object space to world space. A world position is the matrix times the object position extended with a fourth component of 1. |
| Custom index | A 24-bit value that hits report. |
| Mask | 8 bits. A ray hits the instance only when the ray's mask and this mask share a bit. |
| Hit group offset | A 24-bit value that a hit adds to its geometry index to give its record. |
| Bottom-level structure | The structure the instance places. Its build is recorded before the top-level build that reads the instance, in the same recording or an earlier one. |

### Hits

A ray reports the nearest triangle it hits within its interval.

| Value | Definition |
| --- | --- |
| Record | The instance's hit group offset plus the geometry index. A shader binding table maps it to a hit group. |
| Custom index | The instance's custom index. |
| Geometry index | The index of the hit geometry in its bottom-level structure. |
| Primitive index | The index of the hit triangle in its geometry. |

### Lifetime

| Event | Effect |
| --- | --- |
| Creation | The structure stays available to every trace until it's destroyed, whether or not a command names it. |
| Bottom-level build | Takes effect when its recording executes. A recording dropped before it executes builds nothing, and the structure can be built again. The GHI provides the scratch memory of every build. |
| Compaction | Starts when a bottom-level build completes and ends within a few frames. The structure keeps its handle and reports the same hits, and its size drops to the compacted size. |
| Top-level build | Recorded in a frame from the instances the build receives. It writes that frame's copy, which the descriptor sets the frame binds read. A copy keeps what its last build wrote. |
| Destruction | Invalidates the handle at once. The structure stays valid until every frame recorded before the destruction completes. A top-level copy built with an instance of a destroyed bottom-level structure is built again before a later frame traces it. |

### Pipelines

| Rule | Definition |
| --- | --- |
| Shaders | One ray generation shader, and one closest-hit shader for each hit group. Each shader takes its own specialization constants, so two hit groups can share a shader with different constants. |
| Descriptor sets | The ray generation shader binds every set it declares, whether it uses the set or not. A closest-hit shader declares the first sets the ray generation shader declares, in the same order, or fewer, and can use resources of those sets that the ray generation shader doesn't. |
| Push constants | Shared by the ray generation shader and every closest-hit shader. |
| Payload | Each closest-hit shader takes the payload the ray generation shader passes it. The GHI doesn't check that their payload types agree. |
| Calls | Only the ray generation shader runs hit groups. |
| Invocations | Ray tracing shaders share no workgroup memory, don't synchronize with each other, and use no subgroup operations. |

### Shader binding tables

| Event | Effect |
| --- | --- |
| Creation | The table holds no records. |
| Write | Replaces the table's records for one pipeline, with one record for each entry of a list of hit group numbers: record *i* runs the hit group that entry *i* names. Traces recorded after the write use the new records, and traces recorded before it keep the records they were recorded with. |
| Trace | Uses the table with the pipeline its last write named. Every record a hit reports is below the table's record count. |

### Launches

A trace launches the ray generation shader over an extent.

| Value | Definition |
| --- | --- |
| Launch size | The extent of the trace: a width, a height, and a depth. A height or a depth of 0 counts as 1, so a launch over a line or a rectangle can leave the dimensions it doesn't use at 0. |
| Invocations | One for each point of the launch size: the width times the height times the depth. A launch size with a width of 0 runs none. |
| Launch index | The point an invocation runs for. Each component is below the launch size's. |

## Limits

| Limit | Value |
| --- | --- |
| Frames in flight | 3 |
| Resources per descriptor set layout | 64 |
| Counters per frame | 512 |
| Texture copy row pitch alignment | 256 bytes |
| Push constants | Within the pipeline's declared ranges, at offsets and sizes that are multiples of 4 on Vulkan and Direct3D 12 |
| Metal argument table buffer slots | 31; vertex buffers below slot 15 |
| Direct3D 12 constant buffer view | 64 KiB, 256-byte aligned |
| Instance custom index, hit group offset, and hit record | Below 2^24 |
| Instance mask | 8 bits |
| Instances per top-level structure | The count given at creation |

## Errors

| Error | Cause |
| --- | --- |
| Instance, device, and context creation | A message naming what failed. |
| Shader creation | GLSL compilation failed, or SPIR-V wasn't aligned to four bytes. |
| Texture transfer | Unsupported source, format, subresource, layout, or handle; a missing transfer-source use; an allocation or mapping failure. |
| Resource I/O | An empty batch; unsupported compression; an invalid path, handle, range, state, or layout; queue creation, file open, or execution failure; cancellation. |
| Ray tracing | A structure created without ray tracing support; a bottom-level structure without geometry, or a top-level structure for zero instances; geometry whose buffers lack the acceleration structure build use, whose ranges pass a buffer's end, or whose offsets, stride, or index format break the triangle geometry rules; a destroyed handle; a second bottom-level build of a structure, unless the recording that held the first was dropped before it executed; a top-level build outside a frame, with more instances than the structure holds, or with an instance whose bottom-level structure has no recorded build; a custom index or hit group offset of 2^24 or more; a ray tracing pipeline without a ray generation shader or a hit group, with a shader of another stage, or with a closest-hit shader that declares a set the ray generation shader doesn't declare at the same position; a shader binding table write that names a hit group the pipeline doesn't have; a trace with a table that was never written, or that was written for another pipeline than the one bound. |
