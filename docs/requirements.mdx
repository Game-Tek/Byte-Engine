Check these requirements before you build Byte Engine.

## Hardware

- On Linux, a GPU that supports Vulkan 1.3 or higher
- On Windows, a feature-level 12.2 GPU and driver with Shader Model 6.9,
  Enhanced Barriers, native 16-bit operations, wave operations, and the required
  64-bit integer atomic capabilities
- A CPU that supports AVX2 or higher on x64 platforms
- 4 GB of RAM

## Software

Byte Engine requires the nightly Rust toolchain pinned in `rust-toolchain.toml`.
You also need the development tools for your platform:

- Linux with Vulkan development packages
- macOS with full Xcode and its Metal Toolchain component
- Windows 10 version 1909 or newer with the servicing revisions required by the
  [Agility SDK loader](https://devblogs.microsoft.com/directx/gettingstarted-dx12agility/),
  Visual Studio Build Tools, the Windows SDK, and the pinned app-local Agility
  SDK and DXC runtimes

Follow the [environment setup guide](/docs/use/setup/environment) to install the
tools and packages for your operating system.
