---
title: Prepare resources
description: Turn your application's source assets into the resources a release build loads.
icon: Storage
---

Bake your application's assets into resources before you package a release, and
let debug builds bake them on demand while you work.

<Steps>
<Step>

### [Install BELD](/docs/use/resources/install-beld)

Install the asset-baking command-line tool.

</Step>
<Step>

### [Use BELD](/docs/use/resources/beld)

Bake, inspect, query, and delete resources.

</Step>
<Step>

### [Bake application resources](/docs/use/resources/bake)

Link the engine assets, bake everything a release loads, and leave unused render
features out.

</Step>
</Steps>

Before you bake, [author the assets](/docs/use/resources/author) that you write
by hand: materials, flipbooks, environment maps, and detail-level settings.
While you develop, [load resources in debug builds](/docs/use/resources/debug-loading)
to bake missing or stale assets on demand. The formats you can author, with
their fields, are in the [asset formats reference](/docs/reference/assets).
